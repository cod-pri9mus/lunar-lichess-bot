# Lunar — панель Lichess-бота

Расширение показывает плавающую панель статуса локального бота прямо на
`lichess.org` — ещё до начала партии.

## Установка (один раз)

1. Запустите бота из корня проекта:
   ```powershell
   .\.venv\Scripts\python.exe run.py
   ```
2. Откройте `chrome://extensions` (или `edge://extensions`).
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное** и выберите папку `browser_extension`.
5. Откройте или обновите вкладку `lichess.org` — в правом нижнем углу
   появится панель **LUNAR**.

## Порт

По умолчанию бот поднимает панель на `http://127.0.0.1:8765/`.
Если порт занят, бот попробует следующие; фактический адрес будет в консоли
(`browser panel: ...`). Чтобы указать расширению другой порт:

`chrome://extensions` → **Lunar** → **Подробнее** → **Параметры расширения** →
введите порт → **Сохранить и проверить**.

## Что показывает

- статус: ожидание, играет, думает, пауза, нужна помощь;
- чей ход, цвет, число ходов и партий;
- кнопки: пауза/продолжить, пересканировать доску, открыть полную панель.

Полная панель (`Открыть панель`) показывает живой превью доски, FEN, ASCII,
журнал и расширенные кнопки.
